What is JSON?
-------------

JSON stands for **JavaScript Object Notation**.

JSON is a simple text format used to store and exchange data between
applications. APIs commonly use JSON to send data from a server to a client.

JSON is easy for both humans and computers to read.


Basic JSON representation
------------------------

JSON stores data as key-value pairs:

```text
"key": "value"
```

- The key describes the data.
- The value is the actual data.
- A colon (`:`) separates the key and value.
- Different key-value pairs are separated by commas.
- Curly brackets (`{ }`) represent an object.


Small JSON example
------------------

```json
{
  "name": "Aarav",
  "age": 20,
  "isStudent": true
}
```

Representation of this JSON:

```text
name      → "Aarav"
age       → 20
isStudent → true
```

Here:

- `"name"` has a string value: `"Aarav"`.
- `"age"` has a number value: `20`.
- `"isStudent"` has a boolean value: `true`.


JSON array representation
-------------------------

Square brackets (`[ ]`) represent a list or array:

```json
[
  {
    "id": 1,
    "name": "Laptop"
  },
  {
    "id": 2,
    "name": "Phone"
  }
]
```

The JSON above represents a list containing two products.

-----------------------------------------------------------------

JSON vs JavaScript object 
-------------------------

JSON and a JavaScript object may look similar, but they are different:

| JSON |                                       JavaScript object |
|------|                                   -------------------|
| A text format used to exchange data. |        A value used directly by JavaScript code. |
| Property names must use double quotes.       Property names can usually be unquoted. |
| Strings must use double quotes. |               Strings can use single or double quotes. |
| Supports strings, numbers, booleans, arrays, objects, and `null`. |      Can also contain functions, `undefined`, `Date` objects, and other JavaScript values. |
| Cannot contain comments or trailing commas. |             Can contain methods and, depending on the syntax, trailing commas. |

The same data looks like this:

JavaScript object:

```javascript
const user = {
  name: "Aarav",
  age: 20,
  isStudent: true
};
```

JSON:

```json
{
  "name": "Aarav",
  "age": 20,
  "isStudent": true
}
```

The JavaScript object is available as a value inside the program. JSON is
plain text, so it can be saved in a file or sent through an API.


Converting a JavaScript object to JSON
--------------------------------------

Use `JSON.stringify()` to convert a JavaScript object into a JSON string:

```javascript
const user = {
  name: "Aarav",
  age: 20,
  isStudent: true
};

const jsonUser = JSON.stringify(user);

console.log(jsonUser);
// {"name":"Aarav","age":20,"isStudent":true}
```

The result is a string, not a JavaScript object:

```javascript
console.log(typeof jsonUser); // "string"
```

Complete conversion flow
------------------------

```javascript
const originalObject = {
  name: "Aarav",
  skills: ["HTML", "CSS", "JavaScript"]
};

// JavaScript object -> JSON string
const jsonString = JSON.stringify(originalObject);

// JSON string -> JavaScript object
const convertedObject = JSON.parse(jsonString);

console.log(convertedObject.skills[2]); // "JavaScript"
```


Example API request and response
--------------------------------

Suppose we want to get a list of users from an API. The API endpoint might
look like this:

```text
GET https://api.example.com/users
```

The client sends a `GET` request, and the server returns JSON:

```json
{
  "success": true,
  "users": [
    {
      "id": 1,
      "name": "Aarav",
      "email": "aarav@example.com"
    },
    {
      "id": 2,
      "name": "Meera",
      "email": "meera@example.com"
    }
  ]
}
```

In JavaScript, `fetch()` sends the request and `response.json()` converts the
JSON response into a JavaScript object:

```javascript
async function getUsers() {
  const response = await fetch("https://api.example.com/users");
  const data = await response.json();

  console.log(data.success);       // true
  console.log(data.users[0].name); // Aarav
  console.log(data.users[1].email); // meera@example.com
}

getUsers();
```

An API can also receive JSON. For example, to create a new user, the client
can send a `POST` request:

```text
POST https://api.example.com/users
Content-Type: application/json
```

Request body:

```json
{
  "name": "Rohan",
  "email": "rohan@example.com"
}
```

The JavaScript request would look like this:

```javascript
const newUser = {
  name: "Rohan",
  email: "rohan@example.com"
};

const response = await fetch("https://api.example.com/users", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify(newUser)
});

const createdUser = await response.json();
console.log(createdUser);
```

Here, `JSON.stringify(newUser)` converts the JavaScript object into JSON text
before it is sent to the server. The server converts that JSON text back into
data, creates the user, and returns a JSON response.

POST — Create data
``````````````````
Suppose we want to create a new student.
async function createStudent() {

    const student = {
        name: "Abhinash",
        age: 21
    };

    const response = await fetch(
        "https://example.com/api/students",
        {
            method: "POST",

            headers: {
                "Content-Type": "application/json"
            },

            body: JSON.stringify(student)
        }
    );

    const data = await response.json();

    console.log(data);
}

Notice the important parts:
method: "POST"

means:
Create something.

And:
body: JSON.stringify(student)

converts the JavaScript object into a JSON string so it can be sent in the request body.

how to throw the error 
``````````````````````

it did not automatically throw we have to create manully

A 404 or 500 response does not automatically make fetch() reject.
So in real code, check:
if (!response.ok) {
    throw new Error("Request failed");
}

Example:
async function getProducts() {
    try {
        const response = await fetch(
            "https://example.com/api/products"
        );

        if (!response.ok) {
            throw new Error("Failed to fetch products");
        }

        const data = await response.json();

        console.log(data);

    } catch (error) {
        console.log(error.message);
    }
}
