What is npm? 

npm stands for Node Package Manager. It is the default package manager for
Node.js and is used to install, update, remove, and manage JavaScript
packages and project dependencies.

Common npm commands:

npm init
Creates a package.json file for a new project.

npm install package-name
Installs a package locally in the project.

npm install
Installs all dependencies listed in package.json.

npm install -g package-name
Installs a package globally on the computer.

npm run script-name
Runs a script defined in package.json.

Example:

npm install express

This command installs the Express.js package in the current project.

.env vs .env.production

.env.development

VITE_API_URL=http://localhost:3000


Used by default when running Vite in development mode.


.env.production

VITE_API_URL=https://api.example.com


Used by default for a production build.



What is .gitignore
A .gitignore file tells Git which files and folders it should normally ignore when tracking changes.
Example .gitignore:
node_modules/
dist/
.env
.env.local

What should you upload to GitHub?
File or folder	Normally commit?
src/	Yes
package.json	Yes
package-lock.json	Yes
node_modules/	No
.env with local settings or secrets	No
.env.example with placeholder values	Yes

Four important Git commands
Command	What it does
git status	Shows changed and untracked files
git add .	Stages changes for the next commit
git commit -m "message"	Records a snapshot of staged changes
git push	Sends local commits to a remote repository
